Вариант 3 · обувь
Имеется 6 единиц материала. Пара обуви требует 3 или 1 единицу и приносит 1200 или 1100 рублей. Принята трактовка неоднозначного условия: не более двух пар КАЖДОГО вида. Использовать весь материал необязательно.

Условие
Ёмкость B = 6
Максимизировать Σ Fⱼ(xⱼ), Σ aⱼ·xⱼ ≤ B; xⱼ — целые неотрицательные.
Обувь 1: вес 3, 0 ≤ x ≤ 2; F(0…2) = 0, 1200, 2400
Обувь 2: вес 1, 0 ≤ x ≤ 2; F(0…2) = 0, 1100, 2200
