Вариант 1 · контейнеры

Условие
Ёмкость B = 4
Максимизировать Σ Fⱼ(xⱼ), Σ aⱼ·xⱼ ≤ B; xⱼ — целые неотрицательные.
Контейнер 1: вес 1, 0 ≤ x ≤ 3; F(0…3) = 0, 5, 15, 18
Контейнер 2: вес 1, 0 ≤ x ≤ 3; F(0…3) = 0, 3, 6, 14
