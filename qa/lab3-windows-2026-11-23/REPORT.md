## Исправления, найденные на Windows

1. Тест чтения сохранённого JSON полагался на системную кодировку; теперь явно читает UTF-8. В самом формате приложения UTF-8 уже был задан.
2. Windows обрабатывает перенос фокуса между редакторами через очередь событий. Убрано лишнее переключение фокуса на canvas при открытии редактируемой клетки; устаревшее событие FocusOut больше не закрывает новый редактор. Клавиатурный тест дожидается обработки каждого действия и дополнительно проверяет, что Escape действительно закрыл редактор.
3. Отложенная начальная перерисовка уничтоженной таблицы вызывала фоновые Tcl-ошибки. Задача перерисовки теперь отменяется при уничтожении таблицы. Добавлена регрессионная проверка.

В итоговом Windows-логе нет сообщений `invalid command name` и `bgerror`. Временная диагностическая трассировка удалена. Обязательные тесты не отключались.
