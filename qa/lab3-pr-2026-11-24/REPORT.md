## Windows и границы проверки

На ветке PR workflow «Загрузка рюкзака — tests / EXE» запускает полный набор тестов на Python 3.12, проверяет запуск из исходников, собирает Windows x64 EXE и запускает упакованный файл с `--smoke-test`. Результат и артефакт доступны в Checks соответствующего PR. Полные учебные сценарии проверяются из исходников; для EXE проверяется запуск.

Сравнение с оригинальным EXE и методичкой зафиксировано в [предыдущей матрице соответствия](../lab3-parity-2026-11-23/REPORT.md). Интерфейс преподавателя отложен пользователем. Неоднозначности вариантов 3 и 5 явно описаны в задачах. JSON сохраняет условие, а не сессию между запусками приложения.
