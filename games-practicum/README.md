# Игры · Практикум

Учебное Windows-приложение для лабораторной №4: решение матричной игры в смешанных стратегиях, седловая точка, сведение к паре двойственных задач линейного программирования. Python 3.12+ и Tkinter, без внешних зависимостей для работы.

## Запуск

Готовый EXE собирается в GitHub Actions: workflow **«Игры — tests / EXE» → Run workflow** → после завершения скачайте артефакт **Games-Practicum-windows-x64** (содержит `Games-Practicum.exe` и папку `variants/`) и запустите exe. Python и интернет для автономного EXE не нужны.

Из исходников: `python app.py` (Python 3.10+ с Tkinter). Для вычислений нет внешних зависимостей.

## Работа с задачей

1. Выберите вариант из списка и нажмите «Загрузить», откройте JSON через «Загрузить вариант из файла» или задайте число строк/столбцов и нажмите «Создать таблицу». Строки — стратегии игрока А (он максимизирует выигрыш), столбцы — стратегии игрока B. Можно отредактировать названия стратегий, саму матрицу и описание сценария прямо в таблице.
2. Нажмите «Приступить к решению →». Условие фиксируется на время учебного сеанса.
3. **Нижняя и верхняя цена игры.** Вычислите и введите α = max из минимумов строк и β = min из максимумов столбцов.
4. **Седловая точка.** Укажите, выполняется ли α = β.
   - Если седловая точка есть — укажите строку и столбец, образующие её (оптимальны чистые стратегии, цена игры равна α).
   - Если седловой точки нет — нажмите «Решить задачи ЛП»: программа сводит игру к паре двойственных задач линейного программирования (с предварительным сдвигом матрицы к положительным значениям, если нужно) и решает их точным симплекс-методом. Показываются только «сырые» решения x, y и Lmin — дальнейшие шаги студент выполняет сам.
5. **Цена игры.** Вычислите и введите ν = ν* − c, где ν* = 1/Lmin — цена игры со сдвинутой матрицей, c — добавленный сдвиг.
6. **Вероятности.** Вычислите и введите вероятности pᵢ = xᵢ·ν* для игрока А и qⱼ = yⱼ·ν* для игрока B.
7. **Результат.** Итоговая цена игры и оптимальные стратегии обоих игроков, количество ошибок и подсказок.

Подсказка текущего этапа появляется только по кнопке «Подсказка» и содержит точный ответ для этого этапа; каждое нажатие увеличивает счётчик «Ошибки / подсказки». Ошибочный ответ не меняет решение и не раскрывает верное значение — текст ошибки описывает правило, а не число. Журнал содержит принятые действия текущего сеанса. «Новая задача» просит подтверждение, если решение не завершено, и возвращает к условию; счётчики и состояние сбрасываются.

## Файлы вариантов

В `variants/` находятся семь JSON-файлов: пример из методички и варианты 1–6. При запуске программа загружает эту папку рядом с `app.py` или exe.

- «Загрузить вариант из файла» — выбрать JSON из любой папки; вариант добавляется в конец списка. Совпадающим названиям добавляется суффикс `(2)`, `(3)`…
- «Загрузить все варианты» — выбрать папку (по умолчанию `variants`). Все JSON проверяются до импорта; только при успехе список заменяется целиком, иначе указывается файл с ошибкой и прежний список сохраняется.
- «Сохранить вариант в файл» — сохранить текущую, в том числе отредактированную таблицу. Имя файла используется как название варианта.

Формат: `matrix` — платёжная матрица игрока А (1–8 строк, 1–8 столбцов, любые рациональные числа как строки: `"0.8"`, `"-4"`, `"1/3"`), `row_labels`/`col_labels` — обязательные названия стратегий игрока А и B, `name` — необязательное название (без него используется имя файла), `description` — необязательный текст сценария. Чтобы добавить, изменить или удалить вариант преподавателю достаточно создать, отредактировать или удалить соответствующий `.json`-файл в `variants/` — формат проверяется при загрузке, повреждённый файл не ломает остальные варианты, его можно сначала открыть через «Загрузить вариант из файла», чтобы увидеть точную причину ошибки.

## Математика

Нижняя цена α = maxᵢ minⱼ aᵢⱼ, верхняя β = minⱼ maxᵢ aᵢⱼ; седловая точка существует при α = β — тогда оптимальны чистые стратегии. Иначе игра сводится к паре двойственных ЛП: игрок А решает minΣxᵢ при A'ᵗx ≥ 1, игрок B — maxΣyⱼ при A'y ≤ 1 (A' — матрица со сдвигом c ≥ 0, делающим все элементы строго положительными). Решения совпадают по двойственности: Lmin = Lmax; цена сдвинутой игры ν* = 1/Lmin, исходная цена ν = ν* − c; вероятности pᵢ = xᵢ·ν*, qⱼ = yⱼ·ν*. Обе ЛП решаются собственным точным двухфазным симплекс-методом (`fractions.Fraction`, без промежуточного float), независимо проверенным в `test_solver.py` против условий минимакса (не повторным симплексом).

## Проверки и сборка

```bash
python -m unittest discover -v
python app.py --smoke-test
python -m pip install -r ../.github/requirements-build.txt
python build.py
```

Проверяются седловые и бесседловые игры, пример и все варианты методички, игра «камень-ножницы-бумага» (отрицательные элементы, сдвиг), случайные матрицы 2×2–5×5 против условий оптимальности минимакса, прямые проверки симплекса (включая фазу I, несовместность и неограниченность), JSON-варианты (валидация, round-trip, дедупликация, «всё или ничего» при импорте папки) и полный учебный сценарий интерфейса с подсказками, ошибками и сбросом.

`build.py` запускается на Windows и создаёт `dist/Games-Practicum.exe` вместе с `dist/variants/`, а также копию `Игры-Практикум.exe` в корне проекта.

## Ограничения первой версии

- Нет масштабирования таблиц и построения их вручную по клеткам — матрица отображается и редактируется обычными текстовыми полями.
- Не реализовано удаление доминируемых стратегий как отдельный учебный шаг; программа всегда применяет сведение к линейному программированию, даже если игру можно упростить до меньшей матрицы.
- Отдельной страницы преподавателя для управления вариантами нет — варианты редактируются как JSON-файлы в `variants/` (см. раздел выше).
- Полная визуальная приёмка интерфейса и проверка на другом Windows-компьютере остаются отдельным этапом.
