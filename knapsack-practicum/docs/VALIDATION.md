# Проверка лабораторной №3

Актуальные сценарии и снимки интерфейса: [проверка перед PR от 24.11.2026](../../qa/lab3-pr-2026-11-24/REPORT.md).

Автотесты проверяют вычисления против независимого полного перебора, все шесть задач и десять оптимальных планов, промежуточные таблицы, альтернативные максимумы, восстановление y/x, ошибки, подсказки, JSON и интерфейс. Отдельно проверяются вставка матрицы из Excel, F(0), общий и индивидуальные лимиты, автоматический выбор примера, переименование при сохранении, сохранение прогресса при возврате к условию и сброс после изменения данных.

Windows workflow для PR выполняет полный набор тестов, запуск исходного приложения, сборку PyInstaller и запуск упакованного EXE с `--smoke-test`. Архив с EXE, вариантами и документацией публикуется как артефакт проверки.

## Сравнение с оригиналом

[Матрица соответствия и Windows-сценарии оригинала](../../qa/lab3-parity-2026-11-23/REPORT.md) фиксируют прохождение исходного EXE, намеренные ошибки и сравнение всех шагов лабораторной. В этом отчёте сохранены результаты и снимки версии от 23.11.2026; более поздние изменения интерфейса описаны в актуальном отчёте выше.

Первичные проверки: [macOS](../../qa/lab3-2026-11-23/REPORT.md), [Windows](../../qa/lab3-windows-2026-11-23/REPORT.md). Папка `qa` находится в репозитории и не включается в Windows-дистрибутив. Снимки в `docs/screenshots/` относятся к первоначальному интерфейсу.

## Ограничения

- Отдельная страница преподавателя и общий каталог вариантов отложены пользователем. Доступны редактор условия и JSON open/save.
- Варианты 3 и 5 содержат неоднозначности методички; принятые трактовки указаны в описаниях задач.
- TXT содержит протокол расчётов, но не заменяет индивидуально оформленный отчёт студента.
- Возврат к условию сохраняет текущую сессию в памяти; JSON сохраняет только условие.
- Полное покрытие машинного кода оригинала не заявляется; границы исследования описаны в [REVERSE_ENGINEERING.md](REVERSE_ENGINEERING.md).
