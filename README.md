# Учебные практикумы

Один репозиторий для четырёх Windows-программ на Python 3.12 с Tkinter.

| Папка | Программа |
| --- | --- |
| `ktz-practicum` | Лаб. 1 — транспортная задача методом потенциалов; реализована. |
| `ldp-practicum` | Лаб. 2 — дискретное целочисленное программирование (LDPTechs); заготовка. |
| `knapsack-practicum` | Лаб. 3 — задача о загрузке рюкзака; заготовка. |
| `games-practicum` | Лаб. 4 — матричные игры и смешанные стратегии; заготовка. |

В `source/` сохранены исходные методички и старые exe. Новые заготовки пока показывают только окно с названием и статусом.

Готовые варианты в файлах для каждой программы находятся в папке `variants/` внутри папки соответствующей программы.

**Запуск и тесты:** перейдите в папку нужной программы и выполните `python app.py` или `python -m unittest discover -v`.
Тесты каждой программы автоматически запускаются в GitHub Actions при PR в `main` и push в `main`.

**Скачать exe:** Actions → workflow нужной программы → **Run workflow** → после успешного завершения **Artifacts** → архив с exe. Сборка выполняется вручную после тестов, артефакт хранится 30 дней. Для заготовок собирается только стартовое окно.
Кнопки появятся после добавления workflows в основную ветку репозитория.
