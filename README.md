# Учебные практикумы

Один репозиторий для четырёх Windows-программ на Python 3.12 с Tkinter.

| Папка | Программа |
| --- | --- |
| `ktz-practicum` | Лаб. 1 — транспортная задача методом потенциалов; реализована. |
| `ldp-practicum` | Лаб. 2 — ЛП-Практикум: точный симплекс, целочисленные отсечения, резервное ветвление, пошаговые таблицы и JSON/INI; реализована первая версия. |
| `knapsack-practicum` | Лаб. 3 — рюкзак: пошаговое динамическое программирование, проверка таблиц и восстановления, новый интерфейс; реализована. |
| `games-practicum` | Лаб. 4 — матричные игры и смешанные стратегии; заготовка. |

В `source/` сохранены исходные методички и старые exe. Заготовка лабораторной 4 пока показывает только окно с названием и статусом. Описание нового тренажёра рюкзака и разбора оригинального EXE — в [README лабораторной 3](knapsack-practicum/README.md).

Готовые варианты в файлах для каждой программы находятся в папке `variants/` внутри папки соответствующей программы.

**Запуск и тесты:** перейдите в папку нужной программы и выполните `python app.py` или `python -m unittest discover -v`.
Тесты каждой программы автоматически запускаются в GitHub Actions при PR в `main` и push в `main`.

Для независимых проверок лабораторной 2 перед тестами установите `python -m pip install -r requirements-test.txt` из `ldp-practicum`. Само приложение использует только стандартную библиотеку Python. Описание функций и ограничений — в [README ЛП-Практикума](ldp-practicum/README.md).

**Скачать exe:** Actions → workflow нужной программы → **Run workflow** → после успешного завершения **Artifacts** → архив с exe. Сборка выполняется вручную после тестов, артефакт хранится 30 дней. Для заготовок собирается только стартовое окно.
Кнопки появятся после добавления workflows в основную ветку репозитория.
