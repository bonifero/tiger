# Общие требования к учебным программам

- Подготовить четыре программы в едином стиле, с общими принципами работы и подсказок.
- Не показывать сразу явные указания, раскрывающие способ выполнения шага или правильный ответ. Такие пояснения доступны только по запросу через «Подсказку». Формулы можно оставлять в основном интерфейсе.
- При ошибке сообщать, что ответ неверный, без объяснения правильного решения. Объяснение доступно только через «Подсказку».
- Считать и показывать количество ошибок и использованных подсказок. Не ограничивать их количество и не сбрасывать решение при достижении какого-либо количества. Решение о зачёте принимает преподаватель.
- На любом этапе решения дать студенту возможность начать новую задачу. По команде «Новая задача» сбрасывать текущее решение и возвращать студента в главное меню.
- Предоставить преподавателю возможность добавлять, изменять и удалять варианты через отдельную страницу с удобным интерфейсом. Варианты загружать из отдельного файла.
- Написать краткую инструкцию по изменению, добавлению и удалению вариантов.
- Передать преподавателю исходный код программ.
